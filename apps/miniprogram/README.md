# 小仁移动端（微信小程序）

这是从《小仁-小程序形态规格-v1.0》落出的可运行工程，不是截图稿。

已完成：

- 首页：向导/随行切换，调用 `config.js` 中配置的 `/task` 接口。
- 行程：本机离线保存下一段行程与倒计时，不伪造票价、余票和航班号。
- 找人：使用脱敏的示例部门/岗位地图；请替换为自己的组织数据。
- 我：服务状态、能力边界和离线数据清理。

导入微信开发者工具前：

1. 把 `project.config.json` 的 `touristappid` 替换为你的小程序 AppID。
2. 修改 `config.js` 的 `apiBase`，并在微信公众平台把对应 HTTPS 域名加入 request 合法域名。
3. 员工身份绑定、订阅消息、报销拍照仍需要你自己的 AppID、模板 ID 与后端绑定表。

开发工具中可临时关闭“校验合法域名”做联调；正式体验版必须配置合法域名。
